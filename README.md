# TALK TO TEXT PRO

A full-stack meeting transcription and meeting intelligence application that converts recorded meetings into structured, readable, and downloadable reports.

The application can:

* Transcribe meeting audio/video
* Clean and organize transcripts
* Optionally translate transcripts
* Generate AI-powered meeting intelligence using Google Gemini
* Generate summaries and key discussion points
* Identify decisions and action items
* Extract deadlines and assigned tasks when available
* Store meeting history in MongoDB Atlas
* Generate downloadable PDF reports

# HOW IT WORKS

---

## 1. Upload Meeting

The user selects an audio or video recording from the Transcribe page.

Supported formats:

* MP3
* WAV
* MP4

The user can also provide an optional meeting title.

---

## 2. File Validation

The Flask backend validates the uploaded file before processing it.

The backend checks:

* Whether a file was provided
* Whether the file has a filename
* Whether the file uses a supported extension
* Whether the uploaded file can be processed

Invalid files are rejected with an appropriate error message.

---

## 3. Transcription

The uploaded meeting is processed to generate a text transcript containing the spoken content of the recording.

The transcription stage converts the meeting recording into text that can then be analyzed and processed.

---

## 4. Transcript Cleaning

The generated transcript is cleaned and formatted to make it easier to read.

The cleaning process can remove unnecessary filler words and improve the overall readability of the transcript without changing the intended meaning.

---

## 5. Optional Translation

Users can optionally translate the transcript into another language.

If the user selects:

```text
No translation
```

the original transcript remains unchanged.

Translation is handled using the `deep-translator` package.

---

## 6. AI Meeting Intelligence

The cleaned transcript is sent to Google Gemini for analysis.

Gemini analyzes the meeting and generates structured information such as:

* Summary
* Key discussion points
* Decisions made
* Action items
* Assigned tasks
* Deadlines
* Speaker information
* Other relevant meeting information

The AI response is converted into structured data so that it can be displayed properly in the frontend.

---

## 7. Save Meeting

After processing is complete, the meeting information is stored in MongoDB Atlas.

This allows users to access previously processed meetings through the Meetings section.

---

## 8. Display Results

The React frontend displays the completed meeting information.

Users can view:

* Meeting title
* Meeting date
* Summary
* Key points
* Decisions
* Action items
* Deadlines
* Speaker information
* Original transcript
* Cleaned transcript
* Translation, if requested

---

## 9. PDF Export

Users can generate a PDF report containing the meeting information.

The PDF is generated by the Flask backend using ReportLab.

# ENVIRONMENT CONFIGURATION

---

You can use `.env.example` as a template.

Example:


Replace the placeholder values with your actual credentials.

Example:

```env
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/talktotext
GEMINI_API_KEY=your_actual_gemini_api_key
```

# API ENDPOINTS

---

| Method | Endpoint                       | Description                  |
| ------ | ------------------------------ | ---------------------------- |
| POST   | `/api/transcribe`              | Upload and process a meeting |
| GET    | `/api/meetings`                | List saved meetings          |
| GET    | `/api/meetings/<id>`           | Get one meeting              |
| DELETE | `/api/meetings/<id>`           | Delete a meeting             |
| POST   | `/api/meetings/<id>/translate` | Translate a saved meeting    |

| GET    | `/`                            | Backend health check         |

# TROUBLESHOOTING

---

## MONGO_URI is missing

Make sure the backend contains a `.env` file:

```text
backend/.env
```

and that it contains:

```env
MONGO_URI=your_mongodb_connection_string
```

---

## Gemini API Error

Check that:

* The Gemini API key is correct.
* The API key is present in `.env`.
* The configured Gemini model is available.
* The backend has internet access.
* The backend has been restarted after changing `.env`.

---

## Could Not Reach Backend

Make sure Flask is running:

```bash
cd backend
python app.py
```

The backend should be available at:

```text
http://localhost:5000
```

---

## Frontend Cannot Connect to Backend

Make sure both applications are running:

```text
Frontend
http://localhost:5173

Backend
http://localhost:5000
```

Also make sure Flask-CORS is configured correctly.

---

## Translation Error

Make sure the translation package is installed:

```bash
pip install deep-translator
```

Then restart the backend.

---

## Empty Transcript

Check that:

* The uploaded file contains audio.
* The recording contains understandable speech.
* The file format is supported.
* The transcription service is working correctly.
